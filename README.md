# קליקר למצגות: איך מפעילים לפני הרצאה

1. **במק:** פותחים את "קליקר" (אייקון בשורת התפריטים למעלה). בפעם הראשונה: לאשר הרשאת נגישות (הכפתור בחלון של קליקר מוביל להגדרות).
2. **באייפון:** פותחים את "קליקר", בוחרים את המק ובפעם הראשונה מקלידים את הקוד בן 6 הספרות שמופיע במק. אחרי זה החיבור אוטומטי.
3. **במצגת:** פותחים את המצגת, עוברים למסך מלא ולוחצים פעם אחת בתוכה כדי שהחלון יהיה בפוקוס.

---

**טיפים**
- החיבור עובד גם בלי רשת Wi‑Fi משותפת (חיבור ישיר בין המכשירים), כל עוד ה-Wi‑Fi וה-Bluetooth דלוקים בשניהם.
- **כפתורי ווליום:** באייפון ← ⚙️ ← "שליטה בכפתורי הווליום". עוצמה למעלה = הבא, עוצמה למטה = הקודם.
- **מצב כיס:** מסך שחור. עם כפתורי ווליום, נגיעות במסך לא עושות כלום. בלי כפתורי ווליום: הקשה = הבא, החלקה = הקודם. לחיצה ארוכה ליציאה.
- **גם כשנעול:** רק בגרסה האישית (`./install-iphone.sh`), לא בגרסת האפסטור.
- ביטול הצמדה: במק, ב-✕ ליד המכשיר. באייפון: ⚙️ ← "ביטול ההצמדה".

**מבנה**
- `ios-app/project.yml`: פרויקט XcodeGen עם שתי מטרות:
  - `SlideClicker`: אפליקציית האייפון (`SlideClicker/`)
  - `MacClicker`: אפליקציית המק לשורת התפריטים (`MacClicker/`)
  - `Shared/ClickerProtocol.swift`: הפרוטוקול וההצמדה (HMAC עם מפתח שנוצר בהצמדה)
- `install-iphone.sh`: מתקין את הגרסה האישית על האייפון המחובר בכבל.
- `release/`: סקריפטים לפרסום (אפסטור + DMG למק). הכול מוסבר ב-[RELEASE.md](RELEASE.md).
- `docs/privacy.html`: מדיניות פרטיות (דרושה לאפסטור).
- השרת הישן (`mac-server/`, `start-clicker.sh`) הוחלף באפליקציית המק ולא נכלל בריפו.

הרצת אפליקציית המק מהקוד: `open ios-app/SlideClicker.xcodeproj`, לבחור את הסכמה MacClicker ← Run.
